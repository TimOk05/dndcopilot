# 🎲 Улучшенный генератор персонажей D&D

## 📋 **Обзор**

Создан полноценный генератор персонажей на основе JSON базы данных, который использует:
- **Расы** из `data/персонажи/расы/races.json`
- **Классы** из `data/персонажи/классы/`
- **Заклинания** из `data/заклинания/заклинания.json`
- **Зелья** из `data/зелья/зелья.json`
- **Снаряжение** из `data/персонажи/снаряжение/снаряжение.json`
- **Имена** из `data/персонажи/имена/имена.json` и `names/`

## 🚀 **Новые возможности**

### **1. Полная база данных:**
- **20+ рас** включая экзотические (ааракокра, аасимар, драконорожденный)
- **12 классов** с полными описаниями и способностями
- **1000+ заклинаний** с детальными описаниями
- **50+ зелий** различных типов и редкости
- **Полное снаряжение** с оружием, доспехами и предметами

### **2. Улучшенная генерация:**
- **Расовые черты** - уникальные способности каждой расы
- **Классовые способности** - способности по уровням
- **Реальные заклинания** - из базы данных, не заглушки
- **Настоящие зелья** - с эффектами и редкостью
- **Стартовое снаряжение** - на основе правил D&D

### **3. Детальная информация:**
- **Характеристики** с модификаторами
- **Боевые параметры** (хиты, КД, скорость, инициатива)
- **Расовые черты** с описаниями
- **Классовые способности** по уровням
- **Заклинания** по уровням

- **Снаряжение** с полным списком

## 🎯 **API Endpoints**

### **Основные действия:**
- `POST ?action=generate` - генерация персонажа
- `GET ?action=races` - список рас
- `GET ?action=classes` - список классов
- `GET ?action=race&id=race_id` - информация о расе
- `GET ?action=class&id=class_id` - информация о классе

### **Дополнительные функции:**
- `GET ?action=spells&class=class_id&level=1` - заклинания для класса
- `GET ?action=potions&count=5` - случайные зелья
- `GET ?action=equipment&class=class_id` - снаряжение для класса
- `GET ?action=stats` - статистика базы данных
- `GET ?action=test` - тест API

## 📊 **Примеры использования**

### **1. Генерация персонажа:**
```javascript
const response = await fetch('api/v3/enhanced-characters.php', {
    method: 'POST',
    body: new FormData({
        'action': 'generate',
        'race': 'elf',
        'class': 'wizard',
        'level': 1,
        'gender': 'random',
        'alignment': 'random'
    })
});
```

### **2. Получение заклинаний:**
```javascript
const response = await fetch('api/v3/enhanced-characters.php?action=spells&class=wizard&level=1');
```

### **3. Получение зелий:**
```javascript
const response = await fetch('api/v3/enhanced-characters.php?action=potions&count=5');
```

```php

// Создание персонажа

    'class' => 'wizard',
    'level' => 1
]);
```

### **3. API:**
```bash
# Тест API

# Генерация персонажа
curl -X POST "http://localhost/api/v3/enhanced-characters.php" \
  -d "action=generate&race=elf&class=wizard&level=1"
```
